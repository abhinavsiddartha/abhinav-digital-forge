# Abhinav Digital Forge

Personal portfolio website of **Chamarty Abhinav Siddartha**, showcasing projects, technical skills, achievements, internships, and professional experience in Full Stack Development and Artificial Intelligence.

## Live Website

https://abhinav-digital-forge.vercel.app

## Features

* Professional portfolio
* Project showcase
* Skills and technologies
* Internship and achievements section
* Responsive design
* Contact information

## Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* shadcn/ui
* Vercel

## Local Setup

```bash
git clone https://github.com/abhinavsiddartha/abhinav-digital-forge.git
cd abhinav-digital-forge
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
